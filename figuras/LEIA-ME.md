# Capturas de tela do agente no Voiceflow

| Arquivo | O que mostra |
| --- | --- |
| `voiceflow_01_fluxo.png` | Fluxo do agente: mensagem inicial, captura da resposta do usuário em `last_utterance` e bloco de instruções |
| `voiceflow_02_fluxo_com_chat.png` | Fluxo com o painel de teste aberto (mensagem inicial) |
| `voiceflow_03_entrada.png` | Teste no painel: tema e texto enviados pelo usuário |
| `voiceflow_04_diagnostico.png`, `voiceflow_06_avaliacao.png` | Trechos da avaliação devolvida pelo agente publicado no Voiceflow |
| `voiceflow_05_prompt_global.png` | Tela do *Global prompt* (prompt do sistema) configurado na plataforma |

Atenção: o experimento do artigo **não** usou o fluxo do Voiceflow. Foi executado apenas o prompt do sistema (`prompts/`), chamado diretamente pela API do modelo. O formato das respostas do agente publicado no Voiceflow (capturas 04 e 06) difere do formato exigido pelo prompt avaliado.
